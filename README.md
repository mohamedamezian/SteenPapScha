# MediaPipe HandLandmarker (Web)

Dit project gebruikt **MediaPipe HandLandmarker** om hand-landmarks te detecteren via de webcam en daaruit Rock/Paper/Scissors af te leiden.

# Bron (guide)

- Hand Landmarker (Web JS): https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js

# Run


```bash
py -m http.server 8000
```

Open daarna:

- http://localhost:8000
